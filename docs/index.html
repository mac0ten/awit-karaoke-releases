How to install (Chrome on Android)

The app is not on the Play Store, so Android asks you to allow it once. It takes a minute.

  1. 1

    Download

    Tap Download APK above. It is a big file (songs included), so use Wi-Fi. If Chrome says the file might be harmful, tap Download anyway.

  2. 2

    Open it

    When it finishes, tap Open on the message at the bottom. Or open Files › Downloads and tap awit-karaoke-….apk.

  3. 3

    Allow Chrome, once

    If Android says it can't install apps from this source, tap Settings, turn on Allow from this source, then go back.

  4. 4

    Install

    Tap Install. If Play Protect shows a warning, tap More details › Install anyway.

  5. 5

    Sing!

    Open AWIT Karaoke. New versions come inside the app after this; you only allow it to install updates once.

The remote

Any phone's browser works as a remote: scan the QR code on the karaoke screen, no app needed. For a remote that works like a videoke remote, get Simple IR and pair it in AWIT Karaoke under Phones & TVs › Remote app.

Questions

Is it really free?

Yes. Free app, not for sale. No ads.

Does it need the internet?

No. The songs are inside the app. The TV and the phones only need to be on the same Wi-Fi as the karaoke phone.

Which phones?

Android 10 or newer, phone or tablet.

Is it safe to install?

Android warns about every app that is not from the Play Store. AWIT Karaoke is signed by us, and the app checks that each update is ours before it installs.

How do updates work?

The app checks this site's releases and offers new versions by itself.
