# AWIT Karaoke releases

AWIT Karaoke is a free karaoke app for Android phones: about 48,000 songs built in, played by its own synthesizer,
with the lyrics on the phone and on any TV's web browser, and a remote on other phones.

**Website: https://mac0ten.github.io/awit-karaoke-releases/** (download, and how to install with Chrome)

**Free app - not for sale.** facebook.com/odendevph

## Install

Download `awit-karaoke-<version>.apk` from the [newest release](../../releases/latest) and open it on the phone
(Android 10 or newer).
The [website](https://mac0ten.github.io/awit-karaoke-releases/#install) shows each step.

## Updates

The app reads `update.json` from this repository's newest release and updates itself. That file is signed, and the
app accepts only files signed with its own key.

This repository holds the release files and the website (`docs/`, served by GitHub Pages).
